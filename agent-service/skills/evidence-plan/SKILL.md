# Evidence plan

1. Call `get_company` for the business, its customers and stage.
2. Break the idea into three to five assumptions that must all be true for it to work, riskiest first: the customer has the problem; they'd try this solution; they'd pay (or switch) for it; and any channel or cost assumption that matters.
3. For each, write the cheapest test that could prove it wrong this week (interviews, a waitlist, a pre-order, a fake-door button) and a pass mark set before the test runs ("at least 3 of 5", "20% join").
4. Describe one smoke test: usually a landing page with a waitlist and a tracked link per channel, run for two weeks.
5. Save everything with `add_assumptions`. Don't propose building anything until the assumptions pass.
